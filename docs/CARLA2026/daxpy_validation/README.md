# daxpy validation set, frozen at CARLA 2026 submission

`daxpy.json` is the trace the paper's validation figures were computed from, kept exactly as submitted.

That is deliberate. Open it with the frozen `MinorFlow.html` in the directory above, which was submitted alongside it and reads it: that pair is self-consistent and reproduces the paper.

`daxpy.S` and `daxpy_stats.txt` are the program and the gem5 statistics the
JSON was produced from, also unmodified.
