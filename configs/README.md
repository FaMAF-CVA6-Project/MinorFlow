# Configurations

`gem5_config_MinorFlow.py` and `gem5_config_Reference_Core.py` are this viewer's own configurations, and run anywhere the repository is checked out.

`CVA6/` is a symlink to `gem5_config_CVA6/gem5/configs/` in the [CVA6 fork](https://github.com/FaMAF-CVA6-Project/CVA6), which is where the matched configuration and `MinorCPU_CVA6.patch` live.
